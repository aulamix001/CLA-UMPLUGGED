# Interface v0.1.1

O seletor A: fica na barra superior, com categorias em submenus na ordem da
referência enviada. Guitars & Bass e Strings ficam em grupos separados. O
rodapé de presets foi removido. Navegação anterior/próximo e bypass continuam
funcionais na barra superior.

Os controles de pré-delay têm aro dourado serrilhado com iluminação fixa,
face escura com textura fina, sombra e indicador branco. Os botões têm moldura
metálica e lente amarela acesa/cinza apagada. Cada estado visual usa o parâmetro
real do plugin. O PNG aprovado continua com o mesmo SHA-256.

Foi acrescentado Default / all modules bypassed no final do banco, preservando
os índices dos 151 programas existentes. O menu oferece os 152 programas uma
única vez, com todos os parâmetros automaticamente mapeados.

Validação local concluída: DSP, presets em 44,1/48/96 kHz, VST3 carregado pelo
host de teste, barra acima da arte, ordem das categorias, cobertura completa
do menu, carga do preset neutro, automação bidirecional, liga/desliga e brilho
dos botões, sequência dos modos e renderização em 802/1100/1604 pixels de largura.

As capturas de interface e menu são produzidas pelo componente JUCE. A captura
aproximada dos pré-delays mostra os valores 100/80 ms e os estados ligado/desligado.
O processo de publicação Windows também gera essas três capturas para revisão.

A fidelidade visual foi conferida com a referência, sem afirmar equivalência
pixel a pixel ou ausência absoluta de defeitos em toda DAW.
